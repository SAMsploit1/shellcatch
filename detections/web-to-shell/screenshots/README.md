# Screenshots

The detection running live on a Wazuh 4.14 single-node stack, with real alerts
generated by the lab (`manager.name: wazuh.manager`, `rule.groups: web_to_shell`).

### 1. Threat Hunting dashboard
![Threat Hunting dashboard](1-threat-hunting-dashboard.png)

17 alerts, 11 at level 12+, zero auth noise. The MITRE ATT&CK breakdown shows
the full chain the detection covers: Web Shell, Exploit Public-Facing
Application, System Information/Network/Owner Discovery, Unix Shell, Ingress
Tool Transfer, Event Triggered Execution.

### 2. Events — rules firing
![Threat Hunting events](2-threat-hunting-events.png)

Every layer in one view: FIM webshell drops (100570/571/572), web-request
payloads (100560/561/562), the interactive-webshell correlation (100550,
level 14), the netcat reverse shell (100531, level 15), and discovery commands
(100520).

### 3. Alert detail — fields
![Alert field detail](3-alert-detail-fields.png)

Expanded documents showing the enrichment: `rule.mitre.id`, `rule.mitre.tactic`,
`decoder.name` (stock `web-accesslog` / syscheck), `data.srcip`, `data.url`,
and the syscheck `sha256_after` / `path` for the dropped webshells.
